# InkRacer コース自動生成（Blender アドオン） v1.2.0

ink-racer-web の「ランダム生成」を Python に移植し、Blender だけでコースを作れるようにしたアドオンです。
ゲームと同じ計算でコース形状・地形・道路・建物・景観を作り、ゲームの「Blender Python」書き出しと同じ取り込み処理で配置します。
動かすのに Node.js やゲーム本体は要りません。

## インストール

1. Blender 4.1 で「編集 > プリファレンス > アドオン > インストール」を開き、`inkracer_course_generator_v1.2.0.zip` を選びます
2. 「InkRacer コース自動生成」にチェックを入れます
3. 3D ビューで N キーを押し、サイドバーの「InkRacer」タブを開きます

## 使い方（ゲームのマップ選択画面と同じ項目）

| 項目 | 内容 |
|---|---|
| レイアウト | サーキット／市街地（深夜ドライブ）／峠道。峠を選ぶと、ゲームと同じ峠向けの初期値になります |
| 地形に沿うルート | 従来の地形・尾根・谷・山腹（サーキットのみ） |
| 見せ場 | 立体交差・長い橋・トンネル・タワーを望む直線（複数選択可） |
| シード、広さ、複雑さ、カーブの強さ、高低差、立体交差数、テクニカル度 | ゲームのスライダーと同じ範囲・刻み |
| この条件で生成／別のシードで生成 | コースを作ります（同じ ID のコースは置き換えます）。1コース 7〜25 秒ほどかかります |
| コースを確認 | 形だけ作って、全長・高低差・立体交差の数と注意（急カーブ・急勾配・道路間隔・交差の上下間隔）を表示します |
| 景観・夜・インク | 配置密度と配置シード、夜（明るさ・街灯の暖かさ・天気など）、インク表現（ゲームの4プリセット・夜用・カスタム・なし） |
| 走行ライン | 生成と同時に、走行ラインをベジェカーブ（自動ハンドル）で自動で打ちます。Car Physics Baker の「コース」にそのまま指定できます。種類は「レーシングライン（アウト・イン・アウト）」か「中心線」 |
| 書き出し | ゲームと同じ形式の「環境JSON」と「Blender Python」を書き出せます |

生成後のシーン一覧には、ゲームと同じ「手描きレンダー」シーン（Cycles＋コンポジットのインク調）もできます。

## 移植した範囲

- コース形状：サーキット6種の型、立体交差の6種の配置、地形ルート4種、見せ場（橋・トンネル・タワーの自動配置と直線化）、市街地、峠
- 道路：路面・路肩・ランオフ・中央分離帯・車線・ピットレーン・橋の下面・擁壁、路面テクスチャ
- 地形・水：起伏、川・海、峠の切り土
- 景観：縁石・ガードレール・照明・パイプ橋・スタート門・橋脚・トンネル・ピット設備、会場設備（トラス橋・LED ゲート・フェンス・タイヤバリア・高速道路・港湾クレーン・高架鉄道・ロープウェイ・ダム・配管・採石場・立体駐車場・パラボラ・工事現場・マーシャルポスト・ピット整備棟・ヘリ・飛行船）、風車、ランダム配置物、市街地の建物・信号・街灯、峠の擁壁・カーブミラー・森
- 動き：電車・ゴンドラ・パラボラ・旗・滝・ヘリ・飛行船・風車・信号（ドライバー）
- 夜：街灯・信号の光、濡れた路面
- インク：輪郭線、紙・ハッチング・網点のコンポジット
- 検証メッセージ（日本語の注意文）

## ゲームとの一致の確認

ゲームのソース（TypeScript）を Node で動かした結果と、移植版の結果を比べました。

- コース形状：23 条件すべて一致（差は 10⁻¹¹ m 以下）
- 検証メッセージ：60 コース・558 件すべて同じ文面・数値
- 書き出しデータ（12 条件、メッシュ 5,663 個、頂点の数値 1,460 万個）：99.3% のメッシュがビット単位で同じ。残りも差は法線の 10⁻¹⁴ 以下
- 例外：1 条件（既定のシード 73）で、高速道路の橋脚 1 本の高さだけが違います。地形の判定がちょうど境目（道路から 110.000 m）にあたり、JavaScript と Python の sin・pow の最後の1桁の丸めの違いで判定が分かれるためです
- Blender で実行した結果：ゲームが書き出す Python を Blender で実行した結果と比べ、1,021 個のオブジェクトのうち上の1つ以外は同じです

## ゲームと違う点

- 看板の絵：ブラウザ版はキャンバスで描いた PNG を貼りますが、Blender 内では描けないため、ゲームの書き出しにもある「文字オブジェクト」で表示します（Node で書き出した場合と同じです）
- 日本語 UI 対策：Blender の「新規データ名を翻訳」が有効だと、ゲームの書き出しスクリプトは既定ノード名の違い（Principled BSDF → プリンシプルBSDF）で止まります。アドオンでは種類でノードを探すように直してあります
- 生成後、3D ビューの表示距離を広げて、コース全体が映る位置に移動します

## 走行ラインのベジェ自動打ち（v1.2.0 で追加。ゲームには無い機能）

- **レーシングライン**：コーナーごとに「手前で外 → 頂点で内 → 立ち上がりで外」を通ります
  - 同じ向きのコーナーが短い直線を挟んで続くときは 1 つのコーナーとして扱います
  - 長いコーナーは早めに内側へ入り、出口の手前まで内側を保ちます
  - 長い直線やゆるい曲がりでは今の側を保ち、次のコーナーの 80 m 手前から寄せます
  - 横方向の動きは 1 m 進むあたり約 0.12〜0.18 m までにして、急に振らないようにしています
  - 中央分離帯のある区間は片側だけを走ります（分離帯はまたぎません）。車線数が変わる所では使える幅も変わります
- **路肩からの余裕**（既定 1.2 m）：ラインが道路の端に近づける限界です。ベジェにした後も、端から 0.94 m 以上離れていることを確認しました（既定コース・峠・立体交差 3 箇所のコース）
- **制御点**：急なコーナーは約 8 m おき、ゆるい所は 14 m、直線は 24 m おきに打ちます（1 周 150〜500 点）。ハンドルは「自動」なので、点を動かすだけで手直しできます
- **中心線**：コース中心（ずらし量を指定可）を同じくベジェで作ります

## タイヤバリヤの形（v1.2.0 で追加）

「景観・夜・インク」の「タイヤバリヤを本物のタイヤの形に」（既定オン）で、コース脇のタイヤバリヤを平らなトレッド・溝・サイドウォール・中央の穴があるタイヤの形にします。
オフにするとゲームと同じドーナツ形になります（ゲームとの一致の確認はオフの状態で行っています）。
